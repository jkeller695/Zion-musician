# Zion Worship Musicians

Sign-up site for Zion Lutheran Church (Camas) worship musicians: Sunday and special services, availability, hymns.

- Live: https://zion-musicians.netlify.app
- `site/` — the website Netlify publishes (`index.html`, `config.js`, `_headers`)
- `supabase/` — database setup (`schema.sql`, optional `seed.sql`)
- `DEPLOY.md` — full setup guide (Supabase, Gmail sign-in emails, Netlify)

## Making changes
Edit files, commit and push to `main`. Netlify publishes the new version automatically within a minute.
Don't drag folders onto Netlify's Deploys page any more: GitHub is now the one master copy.
